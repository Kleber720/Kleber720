## 🚀 Projetos em destaque

### 01 · [Projeto Educação](https://github.com/Kleber720/ProjetoEducacao)

**Aplicação web · React / TypeScript / Node.js / MySQL**

Plataforma de estudos com métodos Pomodoro e Cornell, cadernos com criação, edição e exclusão, vídeos do YouTube e cadastro de usuários. Integra uma interface React com API Express e banco relacional.

### 02 · [MotionVerse](https://github.com/Kleber720/MotionVerse)

**Jogo colaborativo · JavaScript / MediaPipe / Node.js**

Aventura 2D com controle por gestos, rastreamento de mãos e editor de fases. Desenvolvido em turma no Senac Santana; o repositório é um fork do projeto da equipe.

### 03 · [Corinthians Data Analytics](https://github.com/Kleber720/bancodeDadosCOR)

**Banco de dados · SQL / MySQL**

Modelagem de jogadores e estatísticas do clube, integridade referencial e views para consultar participações em gols, saldo de gols e aproveitamento.

### 04 · [Controle de Notebooks Corporativos](https://github.com/Kleber720/ProjetoBancodeDados)

**Projeto em equipe · SQL / MySQL**

Banco de dados para gerenciar funcionários, setores e notebooks, com scripts de procedures, transações, views e segurança. Trabalho colaborativo do Senac Santana.

### 05 · [Sistema de Limpeza](https://github.com/Kleber720/SistemaLimpeza)

**Aplicação de gestão · Python / Flet / JSON**

Projeto de controle de produtos e estoque, com interface gráfica, acesso a dados e organização do código em camadas.

### 06 · [Laboratório de JavaScript](https://github.com/Kleber720/JavaScript)

**Estudos e experimentos · JavaScript / Canvas / HTML / CSS**

Exercícios de lógica, funções, interatividade, desenho com Canvas e experimentos de jogos no navegador.

## 🎯 Competências em prática

- **Interfaces web:** páginas com HTML e CSS, componentes React e interação com JavaScript.
- **Backend e APIs:** rotas Express, validação de dados, DTOs, serviços e integração entre frontend e backend.
- **Dados:** modelagem relacional, consultas SQL, chaves estrangeiras, views e operações de CRUD.
- **Jogos:** lógica em JavaScript, personagens, fases, animações e experimentos com Canvas e gestos.
- **Aplicações Python:** interfaces com Flet, persistência em JSON e organização em camadas.
- **Colaboração e formação:** projetos de turma, versionamento com Git/GitHub, estudo de Design de Games e participação em playtest.

Essas competências refletem os projetos e estudos publicados aqui, em desenvolvimento contínuo.

### About me

Full Stack and Back-End Developer, Technical IT graduate from [SENAC Santana](https://www.sp.senac.br/senac-santana) and Game Design student at [Anhembi Morumbi University](https://portal.anhembi.br/). Currently focused on building scalable web applications, RESTful APIs, and relational database systems from architecture to the data layer. I apply **Clean Architecture**, **SOLID**, **DDD**, and **MVC** principles in personal and collaborative projects, developing full-stack solutions that connect robust back-end services, SQL databases, and modern front-end interfaces.
